# VuoiSapereQuantoCosta.it

Sito statico di calcolatori gratuiti in italiano, pubblicato con Netlify.

- `tools/` – un file per calcolatore (intestazione + HTML + script)
- `src/` – stile e funzioni comuni
- `build.py` – genera il sito in `public/` (eseguire `python3 build.py` prima di ogni commit)
